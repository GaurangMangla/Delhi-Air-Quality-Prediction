Deep learning time-series forecasting system for environmental monitoring.
Tech Stack: Python, TensorFlow/Keras (GRU, LSTM), Pandas, Scikit-Learn
• Developed a time-series forecasting system benchmarking multiple architectures (LSTM, CNN-LSTM); identified GRU
as the optimal model for capturing extreme pollution spikes.
• Engineered 30+ temporal features (lag, rolling, cyclical encoding) across 8 years of data, achieving an R2 Score of 0.85
and a low RMSE of 38.45.
